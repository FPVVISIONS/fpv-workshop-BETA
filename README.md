# 🚁 FPV Workshop

An interactive, lightweight web-based game where you build, configure, and test-fly your own FPV quadcopter from scratch! 

## 🎮 How to Play / Download

* **Play Online:** Click the live link below to play directly in your browser with zero installation needed.
* **Download Locally:** Download or clone this repository, unzip the files, and open `index.html` in any web browser!

## 🛠️ Game Features

* **Choose Your Difficulty:** Select between Easy, Normal, and Hard modes.
* **Realistic Part Selection:** Pick frames, motors, ESCs, FCs, and cameras.
* **Physical Assembly:** Screw down frames and solder motors, cam, and RX to the stack.
* **Betaflight Configuration:** Connect and tune settings in a simulated Betaflight UI.
* **Built-in Simulator:** Export your build straight into the simulator, adjust rates, and test fly!
